# Noah WordPress Theme Package

This folder contains a WordPress-ready theme package for the Noah storefront theme.

## Structure

- `style.css` - WordPress theme header and base styles
- `functions.php` - theme setup, menu registration, and customizer settings
- `header.php` - site header and navigation
- `footer.php` - site footer
- `front-page.php` - homepage layout
- `page.php` - generic page template
- `single.php` - single post template
- `index.php` - fallback archive/posts template
- `assets/css/theme.css` - theme styling additions
- `assets/js/theme.js` - UI interaction script

## WordPress installation

1. Zip this folder.
2. Upload it in WordPress Admin > Appearance > Themes > Add New > Upload Theme.
3. Activate the theme.
4. Add pages named:
   - Home
   - About
   - Contact
   - Shop
   - Product Details
   - Cart
   - Checkout
   - Account
   - Login
   - Blog
   - FAQ
   - Shipping & Returns
   - Privacy Policy
   - Search Results
   - Custom Design
5. In Appearance > Customize, update your brand, colors, and contact details.
